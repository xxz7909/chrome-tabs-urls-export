### 真实 Chrome 人工验收清单

1. 按 `docs/README.md` 加载未打包扩展，确认 Service Worker 控制台没有错误。
2. 开启文件网址和无痕权限，确认管理页的两个权限提示消失。
3. 创建至少两个普通窗口、一个无痕窗口、置顶标签和带颜色/折叠状态的标签组。
4. 分别导出当前窗口与全部窗口 TXT，确认每行一个 URL、顺序正确且重复项保留。
5. 保存完整会话，导出 JSON 后重新导入，确认窗口、置顶、活动页和标签组被恢复到新窗口。
6. 导入 Windows 路径、UNC 路径、`file://`、`chrome://extensions/`、重复 URL 和一条无效文本，确认预览分类正确。
7. 加入一个 Chrome 会拒绝的特殊地址，确认失败项单独报告且其他标签继续打开。
8. 修改标签后等待约 2 秒和 30 秒，确认最新状态与自动历史出现；关闭并重启 Chrome，确认“关闭前状态”可恢复。
